> 이 블로그도 오늘 배운 내용으로 만들었다. 로컬 폴더를 GitHub 저장소에 연결하고, 커밋하고, 푸시해서 GitHub Pages로 배포까지 했다. 🎉

## Git은 뭐고, GitHub는 뭘까

- **Git**: 내 컴퓨터에서 파일의 변경 기록을 저장하고 관리하는 버전 관리 도구
- **GitHub**: Git 저장소를 인터넷에 올려 두고 다른 사람과 공유하고 협업할 수 있는 서비스

Git이 "세이브 포인트를 만드는 기능"이라면, GitHub는 그 세이브 파일을 올려 두는 "클라우드" 같은 느낌이었다.

## 오늘 써 본 명령어

```bash
# 원격 저장소 연결
git remote add origin https://github.com/<내-아이디>/my-blog.git

# 변경 사항 담기 → 기록하기 → 올리기
git add .
git commit -m "첫 글 작성"
git push -u origin main
```

`add`로 올릴 파일을 고르고, `commit`으로 기록을 남기고, `push`로 GitHub에 올리는 흐름이 이제 조금 손에 익었다.

## 재미있었던 점

- 명령어 몇 줄로 내 컴퓨터의 파일이 GitHub에 올라가는 게 신기했다.
- 커밋 기록이 쌓이는 걸 보니 작업 일지를 쓰는 느낌이 들었다.
- 무엇보다 내가 만든 페이지가 실제 웹 주소로 열리는 순간이 제일 짜릿했다!
